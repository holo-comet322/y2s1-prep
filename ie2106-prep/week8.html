Concept 1 of 5

Euler's method: walk along the tangent

The problem: solve y′ = f(x, y) with a known starting value y(x0) = y0, but without a formula for y. Many ODEs have no closed-form solution, or one so messy it's useless — so we walk forward in small steps of size h instead.

yn+1 = yn + h·f(xn, yn)     xn+1 = xn + h
hstep size — how far to walk in x each step
f(xn,yn)the slope of the solution at your current point, given directly by the ODE
h·frise = slope × run — call it an in the slides’ notation (so yn+1 = yn + an)
AnalogyWalking in fog with a compass that only tells you the direction you're facing right now. You take one step straight ahead, re-check the compass, step again. If the path curves, you drift off a little each step — smaller steps (smaller h) mean less drift.
Worked example: y′ = x + y, y(0) = 1, h = 0.1 — find y(0.2) by Euler
  1. Step 1: slope f(0,1) = 0 + 1 = 1, a0 = 0.1(1) = 0.1 ⇒ y(0.1) ≈ 1 + 0.1 = 1.1.
  2. Step 2: slope f(0.1, 1.1) = 1.2, a1 = 0.12 ⇒ y(0.2) ≈ 1.1 + 0.12 = 1.22.
  3. True value 1.24281 — Euler is 1.8% low, because the true curve bends upward and the tangent line always undershoots a convex curve.
Concept 2 of 5

Improved Euler (Heun's method): average two slopes

Idea: Euler uses the slope at the start of the step only. Improved Euler also peeks at the slope at the (predicted) end of the step and uses the average of the two. That cancels most of Euler's drift.

an = h f(xn, yn)    bn = h f(xn+1, yn + an)    yn+1 = yn + ½(an + bn)
anthe Euler step: slope at the start × h
yn + anthe Euler prediction of y at the end of the step (a guess, not the answer)
bnslope at the predicted end point × h — note x moves to xn+1 AND y becomes yn + an
½(a+b)the average step
AnalogyEstimating your car's journey over the next minute. Euler: “I'm doing 60 km/h now, so in a minute I'll have gone 1 km.” Heun: “I'm at 60 now and I'll probably be at 80 by the end, so average 70 ⇒ 1.17 km.” Better, because speed changes during the minute.
Worked example (lecture): y′ = x + y, y(0) = 1, h = 0.1 — y(0.2)
  1. a0 = 0.1 f(0,1) = 0.1. b0 = 0.1 f(0.1, 1 + 0.1) = 0.1(1.2) = 0.12. y1 = 1 + ½(0.1 + 0.12) = 1.11.
  2. a1 = 0.1 f(0.1, 1.11) = 0.121. b1 = 0.1 f(0.2, 1.11 + 0.121) = 0.1(1.431) = 0.1431. y2 = 1.11 + ½(0.121 + 0.1431) = 1.24205.
  3. True 1.24281 — error 0.06% (vs 1.8% for Euler).
Concept 3 of 5

Fourth-order Runge–Kutta (RK4): four slopes, weighted

RK4 samples the slope four times per step — start, two midpoints, end — and takes a weighted average (the midpoints count double).

a = h f(xn, yn)  |  b = h f(xn + h/2, yn + a/2)  |  c = h f(xn + h/2, yn + b/2)  |  d = h f(xn+1, yn + c)  |  yn+1 = yn + (a + 2b + 2c + d)/6

Pattern to remember: each new slope uses the previous increment (half of it for b and c, all of it for d). It's the same “predict then correct” idea as Heun, done more carefully. Error is proportional to h4: halve h and the error drops 16×.

Worked example (lecture): y′ = x + y, y(0) = 1, h = 0.1 — first step
  1. a0 = 0.1 f(0,1) = 0.1.
  2. b0 = 0.1 f(0.05, 1 + 0.05) = 0.1(1.1) = 0.11.
  3. c0 = 0.1 f(0.05, 1 + 0.055) = 0.1(1.105) = 0.1105.
  4. d0 = 0.1 f(0.1, 1 + 0.1105) = 0.1(1.2105) = 0.12105.
  5. y1 = 1 + (0.1 + 0.22 + 0.221 + 0.12105)/6 = 1.110342 (exact 1.110342 — correct to 6 d.p.). Second step gives y(0.2) = 1.242805 (exact 1.242806).
Concept 4 of 5

Second-order ODEs: turn one equation into two

All three methods above only handle first-order ODEs. For y″ = f(x, y, y′) the lecture's trick (“reduce it to a problem you already know how to solve”): name y1 = y and y2 = y′. Then:

y1′ = y2    |    y2′ = f(x, y1, y2)     with y1(x0) = y(x0), y2(x0) = y′(x0)

Now run Euler / Heun / RK4 on both components together, using the old values of both inside every f.

Heun, y1a1 = h·y2,n;   b1 = h(y2,n + a2);   y1,n+1 = y1,n + ½(a1 + b1)
Heun, y2a2 = h·f(xn, y1,n, y2,n);   b2 = h·f(xn+1, y1,n + a1, y2,n + a2);   y2,n+1 = y2,n + ½(a2 + b2)
AnalogyTracking a falling ball: position y1 and velocity y2. Position changes at a rate equal to velocity (y1′ = y2); velocity changes at a rate set by the forces (y2′ = f). Two numbers to update every step, each one depending on the other.
Worked example (lecture): y″ = −y, y(0) = 0, y′(0) = 1, h = 0.2 — Euler
  1. y1′ = y2, y2′ = −y1; start (y1, y2) = (0, 1).
  2. Step 1: y1 = 0 + 0.2(1) = 0.2; y2 = 1 + 0.2(−0) = 1.
  3. Step 2: y1 = 0.2 + 0.2(1) = 0.4; y2 = 1 + 0.2(−0.2) = 0.96.
  4. Step 3: y1 = 0.4 + 0.2(0.96) = 0.592; y2 = 0.96 + 0.2(−0.4) = 0.88. So y(0.6) ≈ 0.592 (the exact value is sin 0.6 = 0.56464; Heun gives 0.56824, RK4 0.56464).

½y″ + 5xy′ − y = ln x, y(1) = 2, y′(1) = 0. Apply Heun's method with h = 0.1 to find y(1.2) and y′(1.2). Write down the explicit formulation of Heun's method.

Try it yourself first, then reveal the solution
Solution

What it's asking: turn the second-order ODE into two first-order ones, then run improved Euler on both together.

  1. Rearrange: y″ = 2(ln x + y − 5xy′). Let y1 = y, y2 = y′:
    y1′ = y2   |   y2′ = f(x,y1,y2) = 2(ln x + y1 − 5x y2)
    Initial: x0 = 1, y1 = 2, y2 = 0.
  2. Heun formulation (the explicit formulas to write): a1 = h y2,n, a2 = h f(xn, y1,n, y2,n); b1 = h(y2,n + a2), b2 = h f(xn+1, y1,n + a1, y2,n + a2); then y1,n+1 = y1,n + ½(a1 + b1), y2,n+1 = y2,n + ½(a2 + b2).
  3. Step 1 (x = 1 → 1.1): a1 = 0.1(0) = 0; a2 = 0.1·2(0 + 2 − 0) = 0.4. b1 = 0.1(0 + 0.4) = 0.04; b2 = 0.1·2[ln 1.1 + (2 + 0) − 5(1.1)(0 + 0.4)] = 0.2[0.09531 + 2 − 2.2] = −0.020938. y1(1.1) = 2 + ½(0 + 0.04) = 2.02; y2(1.1) = 0 + ½(0.4 − 0.020938) = 0.189531.
  4. Step 2 (x = 1.1 → 1.2): a1 = 0.1(0.189531) = 0.018953; a2 = 0.2[ln 1.1 + 2.02 − 5(1.1)(0.189531)] = 0.2[0.09531 + 2.02 − 1.04242] = 0.214578. b1 = 0.1(0.189531 + 0.214578) = 0.040411; b2 = 0.2[ln 1.2 + (2.02 + 0.018953) − 5(1.2)(0.189531 + 0.214578)] = 0.2[0.18232 + 2.038953 − 2.424654] = −0.040676.
  5. Result: y(1.2) ≈ 2.02 + ½(0.018953 + 0.040411) = 2.0497; y′(1.2) ≈ 0.189531 + ½(0.214578 − 0.040676) = 0.2765.

improved Eulersecond-order ODE

For y″ + 2y′ + y = 2u(t), y′(0) = 1, y(0) = 0: use improved Euler with h = 0.1 to approximate y(0.2). (Part (a) solved the same ODE exactly with Laplace — see the ODE section; the exact answer gives you a check.)

Try it yourself first, then reveal the solution
Solution
  1. For t ≥ 0, u(t) = 1. Let y1 = y, y2 = y′: y1′ = y2; y2′ = 2 − 2y2 − y1. Initial: y1 = 0, y2 = 1, h = 0.1.
  2. Step 1: a1 = 0.1(1) = 0.1; a2 = 0.1(2 − 2 − 0) = 0. b1 = 0.1(1 + 0) = 0.1; b2 = 0.1[2 − 2(1 + 0) − (0 + 0.1)] = −0.01. y1(0.1) = 0 + ½(0.1 + 0.1) = 0.1; y2(0.1) = 1 + ½(0 − 0.01) = 0.995.
  3. Step 2: a1 = 0.1(0.995) = 0.0995; a2 = 0.1[2 − 2(0.995) − 0.1] = −0.009. b1 = 0.1(0.995 − 0.009) = 0.0986; b2 = 0.1[2 − 2(0.995 − 0.009) − (0.1 + 0.0995)] = −0.01715.
  4. y(0.2) ≈ 0.1 + ½(0.0995 + 0.0986) = 0.19905. (y′(0.2) ≈ 0.995 + ½(−0.009 − 0.01715) = 0.98193.)
  5. Check against the exact Laplace answer y(t) = 2 − 2e−t − te−t: y(0.2) = 2 − 2.2e−0.2 = 0.19879. Our 0.19905 is within 0.0003 ✓.
Concept 5 of 5

Accuracy & choosing h

MethodOrderError vs hSlopes per step
Euler1st∝ h1
Improved Euler2nd∝ h²2
Runge–Kutta4th∝ h44

Halving h roughly halves Euler's error, quarters Heun's, and divides RK4's by 16. For y′ = x + y at x = 0.2 the slides' comparison is: Euler 1.22000, Heun 1.24205, RK4 1.24281 vs exact 1.24281 (relative errors 1.84%, 0.061%, 0.00003%).

Is smaller h always better? Not without limit: shrinking h reduces the discretisation (truncation) error, but needs more steps, and round-off errors build up. Also each step inherits the previous step's error, so errors grow as you move away from the starting point.

Answer
  1. y1 = y, y2 = y′: y1′ = y2; y2′ = f = 5 + 2t y1. Start t = 0, (2, 0). Three steps of 0.04.
  2. ✍️ Write This Down

Copy these into your own notes:

  • Euler: yn+1 = yn + hf(xn,yn). Improved Euler: a = hf(xn,yn); b = hf(xn+1, yn+a); yn+1 = yn + ½(a+b). RK4: a, b, c, d with midpoints; yn+1 = yn + (a+2b+2c+d)/6.
  • Orders: Euler error ∝ h, Heun ∝ h², RK4 ∝ h4.
  • Second-order ODE: y1 = y, y2 = y′; y1′ = y2; y2′ = (solve the ODE for y″). Initial values y1(x0) = y(x0), y2(x0) = y′(x0). Update BOTH components every step.
  • In Heun, b1 uses y2 + a2 (the predicted derivative); b2 uses y1 + a1 and y2 + a2. Mixing these up is the #1 slip.
  • Number of steps = (target x − x0)/h — e.g. y(2.6) from x0 = 2 with h = 0.2 is 3 steps.
  • When a question says “write down the explicit formulation of Heun's method”, write the system y1′, y2′, then a1, a2, b1, b2, and the two update lines (see the 2023-24 Sem 2 solution above).
