📡 Exam radar — Week 10
  • An ODE solved or analysed with Laplace appears in all 6 finals (10–15 marks, usually Question 3(b)). The pipeline never changes: transform → solve for Y(s) → partial fractions → inverse. Master this page and you own a guaranteed 10–15 marks.
  • Inverse transforms appear again as part (ii) of the transform question (2023-24 S1/S2, 2024-25 S1/S2). Two flavours: distinct/repeated real poles (partial fractions) and complex poles (complete the square → shifted sin/cos). Often combined with an e−as delay.
  • Quiz relevance: Tutorial 10 Q4 (inverse) and Tutorial 11 Q1 (ODE + stability) are in scope. Be able to say why a response is unstable (a pole in the right half-plane comes from the equation itself, not from the input).

Concept 1 of 4

Inverse Laplace by partial fractions

Goal: turn F(s) = N(s)/D(s) back into f(t). Split it into table-sized pieces, then invert each piece. Requires deg N < deg D (otherwise divide first).

  1. Factor D(s) into its roots (poles).
  2. Write one fraction per pole: a distinct pole p gives A/(s−p); a repeated pole gives A/(s−p) + B/(s−p)², one term per power up to the multiplicity.
  3. Find the constants: cover-up for distinct poles (A = [(s−p)F(s)] at s = p); for repeated poles, cover-up gives the highest-power constant, then compare coefficients or plug in a convenient s.
  4. Invert with the table: A/(s−p) → Aept; B/(s−p)² → Btept; A/s → A.
AnalogyPartial fractions is un-adding fractions: 1/2 + 1/3 = 5/6, so given 5/6 you ask “which simple fractions made this?”. Each simple fraction is one “building block” the table knows how to invert.
Tutorial 10 Q4(a): F(s) = (3s+2)/[s(s+4)]

F = A/s + B/(s+4). A = (3·0+2)/(0+4) = 0.5. B = (3(−4)+2)/(−4) = (−10)/(−4) = 2.5. f(t) = 0.5u(t) + 2.5e−4tu(t). Check f(0) = 3 = lim sF(s) = 3 ✓.

Tutorial 10 Q4(b): F(s) = 2/[s(s+1)²] (repeated pole)

F = A/s + B/(s+1) + C/(s+1)². A = 2/1 = 2. C = [2/s] at s = −1 = −2. For B: the s² coefficient of 2 = A(s+1)² + Bs(s+1) + Cs gives 0 = A + B ⇒ B = −2. f(t) = (2 − 2e−t − 2te−t)u(t). Check f(0) = 0 ✓ (F ~ 2/s³ at large s).

Concept 2 of 4

Complex poles (complete the square) and delayed terms

If D(s) has no real roots (e.g. s² − 2s + 5), do not factor it. Instead complete the square so it matches the table forms

e−atcos ωt ↔ (s+a)/((s+a)²+ω²)    e−atsin ωt ↔ ω/((s+a)²+ω²)
  1. Complete the square: s² + bs + c = (s + b/2)² + (c − b²/4). This gives a and ω².
  2. Rewrite the numerator as (a multiple of (s + a)) + (a constant). The multiple gives the cos term; the constant must be divided by ω (and re-multiplied) to get the sin term.
  3. If there is an e−Ts factor, invert the rest first, then replace t by (t − T) everywhere and attach u(t − T).
Tutorial 10 Q4(c): (2s+3)/(s²−2s+5)

s²−2s+5 = (s−1)²+4, so a = −1, ω = 2. Numerator 2s+3 = 2(s−1) + 5. Then 5/((s−1)²+4) = (5/2)·2/((s−1)²+4). f(t) = et(2cos 2t + 2.5 sin 2t)u(t). Growing et because the poles are 1 ± 2j (right half-plane).

Tutorial 10 Q4(d): s e−2s/(s²+16)

Without the delay: s/(s²+16) → cos 4t. Delay by 2: cos[4(t−2)]u(t−2) — every t becomes t−2.

Concept 3 of 4

Solving ODEs with the Laplace transform — the 10–15 mark routine

L{y′} = sY − y(0)   |   L{y″} = s²Y − s·y(0) − y′(0)
Y(s)the transform of the unknown solution y(t).
y(0), y′(0)the initial conditions. They enter automatically when you transform derivatives — that is why Laplace is perfect for initial-value problems.
X(s)the transform of the input on the right-hand side (u(t) → 1/s; a pulse → use the delay rule).
  1. Transform every term using the derivative rules; leave Y as an unknown.
  2. Collect Y: (a·s² + b·s + c)Y = X(s) + (terms from initial conditions).
  3. Divide to get Y(s) = […]/[…]. The denominator polynomial is the characteristic polynomial of the ODE.
  4. Partial fractions (concept 1/2), then invert.
  5. Check: plug t = 0 into y and y′ to recover the initial conditions — a 30-second check that catches nearly every slip.
AnalogyLike using a calculator for a long-division problem: instead of fighting the differential equation directly, you convert to algebra, do the easy algebra, and convert back. The initial conditions get “baked in” at step one.
Tutorial 11 Q1(a): y′ − 2y = u(t), y(0) = 1
  1. sY − 1 − 2Y = 1/s ⇒ (s−2)Y = 1 + 1/s = (s+1)/s.
  2. Y = (s+1)/[s(s−2)] = A/s + B/(s−2). A = 1/(−2) = −0.5; B = 3/2 = 1.5.
  3. y(t) = (−0.5 + 1.5e2t)u(t). Check y(0) = 1 ✓.
Tutorial 11 Q1(b): y″ − 2y′ − 3y = u(t), zero initial conditions
  1. (s² − 2s − 3)Y = 1/s ⇒ Y = 1/[s(s−3)(s+1)].
  2. A (s=0) = 1/[(−3)(1)] = −1/3. B (s=3) = 1/[3·4] = 1/12. C (s=−1) = 1/[(−1)(−4)] = 1/4.
  3. y(t) = (−1/3 + (1/4)e−t + (1/12)e3t)u(t). Check y(0) = −1/3+1/4+1/12 = 0 ✓; y′(0) = −1/4 + 1/4 = 0 ✓.
Concept 4 of 4

Stability of the ODE's response

The answer to “is the response stable and what caused it?” (Tutorial 11 Q1a) is: look at the poles of Y(s). Those from the characteristic polynomial (here s − 2 ⇒ pole at +2) give e2t, which grows — unstable, caused by the system itself (the positive coefficient −2y in y′ = 2y + …, i.e. the output feeds itself positively). A bounded input (u) cannot fix this. The pole at s = 0 from u(t) just gives a constant.

AnalogyA microphone placed too near its speaker: any small sound is fed back and amplified, growing as e2t. The input (the first sound) is tiny and bounded; the instability lives in the loop.

For the second-order case in Q1(b), roots of s² − 2s − 3 = (s−3)(s+1) are 3 and −1: the e3t term makes it unstable too.

ramp pulse t[u(t)−u(t−3)]inverse with delay

(i) Find L{ t[u(t) − u(t−3)] }. (ii) Find the inverse transform of G(s) = 0.4e−s/[s²(s + 0.8)].

Try it yourself first, then reveal the solution
Solution
  1. (i) t[u(t) − u(t−3)] = t u(t) − t u(t−3); with t = (t−3) + 3: = t u(t) − (t−3)u(t−3) − 3u(t−3).
    F(s) = 1/s² − e−3s/s² − 3e−3s/s
  2. (ii) Ignore the e−s first: 0.4/[s²(s+0.8)] = A/s + B/s² + C/(s+0.8). 0.4 = As(s+0.8) + B(s+0.8) + Cs². s = 0: 0.8B = 0.4 ⇒ B = 0.5. s = −0.8: 0.64C = 0.4 ⇒ C = 0.625. A + C = 0 ⇒ A = −0.625.
  3. h(t) = [−0.625 + 0.5t + 0.625e−0.8t]u(t).
  4. Apply the delay: g(t) = [−0.625 + 0.5(t−1) + 0.625e−0.8(t−1)] u(t−1). (Check at t = 1: −0.625 + 0 + 0.625 = 0 ✓.)

shifted damped sin/cosinverse with complex roots

(i) Find the Laplace transform of f(t) = e−t[sin(t−1) + cos(t−1)]u(t−1). (ii) Find the inverse transform of F(s) = (2s² − 6s + 13)/[s(s² − 4s + 13)].

Try it yourself first, then reveal the solution
Solution
  1. (i) Pull out a factor to match the delay: e−t = e−1e−(t−1). So f(t) = e−1·g(t−1)u(t−1) with g(τ) = e−τ[sin τ + cos τ].
  2. G(s) = 1/[(s+1)²+1] + (s+1)/[(s+1)²+1] = (s+2)/(s²+2s+2).
  3. F(s) = e−(s+1)(s + 2)/(s² + 2s + 2).
  4. (ii) Partial fractions with an irreducible quadratic: F = A/s + (Bs + C)/(s²−4s+13). A = 13/13 = 1. Then 2s²−6s+13 = (s²−4s+13) + (Bs+C)s ⇒ s²: 2 = 1 + B ⇒ B = 1; s: −6 = −4 + C ⇒ C = −2.
  5. (s − 2)/[(s−2)² + 9] → e2tcos 3t. So f(t) = [1 + e2t cos 3t] u(t). (Check f(0) = 2; initial-value: lim sF(s) = 2 ✓.)

solve ODE with initial conditionsstep input

y″ + 6y′ + 8y = x(t), x(t) = u(t), y(0) = 2, y′(0) = 1. Find y(t) by Laplace transform.

Try it yourself first, then reveal the solution
Solution
  1. Transform each term (derivative rules): L{y″} = s²Y − sy(0) − y′(0) = s²Y − 2s − 1; L{6y′} = 6(sY − 2); L{8y} = 8Y; L{u} = 1/s.
  2. (s² + 6s + 8)Y = 1/s + 2s + 1 + 12 = (2s² + 13s + 1)/s ⇒ Y = (2s² + 13s + 1)/[s(s+2)(s+4)].
  3. Partial fractions (cover-up): A = (1)/(2·4) = 1/8; B at s = −2: (8 − 26 + 1)/[(−2)(2)] = (−17)/(−4) = 17/4; C at s = −4: (32 − 52 + 1)/[(−4)(−2)] = −19/8.
  4. y(t) = [1/8 + (17/4)e−2t − (19/8)e−4t] u(t). Check: y(0) = 0.125 + 4.25 − 2.375 = 2 ✓; y′(0) = −8.5 + 9.5 = 1 ✓.

solve ODE with exponential input

y″ + 3y′ + 2y = r(t), r(t) = 2e−tu(t), y(0) = 0, y′(0) = 1. Find y(t) by Laplace transform.

Try it yourself first, then reveal the solution
Solution
  1. Transform: s²Y − 1 + 3sY + 2Y = 2/(s+1) ⇒ (s+1)(s+2)Y = 1 + 2/(s+1) = (s+3)/(s+1).
  2. Y(s) = (s + 3)/[(s+1)²(s+2)] (a repeated pole at −1 because the input e−t matches a natural mode).
  3. Partial fractions: A/(s+1) + B/(s+1)² + C/(s+2). C = (−2+3)/(−2+1)² = 1. B at s = −1: (2)/(1) = 2. A + C = 0 (large-s behaviour) ⇒ A = −1.
  4. y(t) = [−e−t + 2te−t + e−2t] u(t). Check: y(0) = −1 + 0 + 1 = 0 ✓; y′(0) = (1 + 2 − 2) = 1 ✓.

solve ODE with step input and initial conditions

y″ + 2y′ + y = 2u(t), y′(0) = 1, y(0) = 0. Use the Laplace transform method to find y(t).

Try it yourself first, then reveal the solution
Solution
  1. Transform: (s²Y − s·0 − 1) + 2(sY − 0) + Y = 2/s ⇒ (s+1)²Y = 1 + 2/s = (s+2)/s.
  2. Y(s) = (s + 2)/[s(s+1)²].
  3. Partial fractions A/s + B/(s+1) + C/(s+1)²: A = 2/1 = 2; C at s = −1: (1)/(−1) = −1; A + B = 0 ⇒ B = −2.
  4. y(t) = [2 − 2e−t − te−t] u(t). Check: y(0) = 0 ✓; y′(0) = 2 − 1 = 1 ✓; as t→∞ y → 2 (the steady state: y = 2u/1).

✍️ Write This Down

Copy these into your notes:

  • ODE routine: transform → collect Y → partial fractions → invert → check y(0), y′(0).
  • L{y′} = sY − y(0); L{y″} = s²Y − sy(0) − y′(0).
  • Distinct pole: A/(s−p) → Aept. Repeated: B/(s−p)² → Btept. Complex: complete the square → e−at(cos, sin).
  • Numerator = k(s+a) + m over ((s+a)²+ω²) ⇒ k e−atcos ωt + (m/ω) e−atsin ωt.
  • Delay e−Ts: invert the rest, replace every t with t−T, multiply by u(t−T).
  • Pole in the right half-plane (root of the characteristic polynomial) ⇒ unstable regardless of input.
