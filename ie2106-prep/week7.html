Concept 1 of 6

Why approximate at all? — and how to measure “how wrong”

Computers are brilliant at +, −, × and therefore at polynomials like ax³ + bx² + cx + d. They are not naturally able to compute sin x, ex, ln x — those are approximated by polynomials inside the machine. Likewise most equations (like x − cos x = 0) have no formula for the answer. So Part II of IE2106 starts with two jobs: (1) replace a complicated function by a polynomial (interpolation) and (2) solve an equation approximately by repeating a calculation (fixed-point iteration).

AnalogyA pocket calculator doesn't know sin(0.7) — it knows a polynomial that is extremely close to sin near 0.7. Interpolation is how someone builds such a polynomial from a few known points, like drawing a smooth road through a handful of survey markers.
absolute error ε = |a − ã|   |   relative error r = |a − ã|/|a|
athe true (exact) value
ãyour approximation of it (the “a-tilde”)
εhow far off you are, in the units of the quantity
rhow far off you are compared with the size of the thing — an error of 1 mm is huge on a 2 mm bolt and invisible on a 2 km road

Slide rule worth copying: a number correct to n significant digits has relative error r < 0.5 × 101−n. Example: ã = 3.14 for π has r = 0.000507 < 0.005 = 0.5×101−3, so 3.14 is correct to 3 significant digits.

Concept 2 of 6

Polynomial interpolation: the core idea

Core idea: given n + 1 points with different x-values, there is a polynomial of degree at most n that passes through all of them. Two points → a straight line; three points → a parabola; four points → a cubic, and so on. That polynomial p(x) then stands in for the real function: f(x) ≈ p(x).

AnalogyTwo nails in a wall fix exactly one straight string. Three nails fix exactly one parabola-shaped chain. More nails, more bend — but always one curve of the matching degree.

The slow way (and why we avoid it): write p(x) = a2x² + a1x + a0, plug in each point to get n+1 equations, and solve the system for the a's. It works, but (1) it is long when there are many points, and (2) if you add one more point you must solve the whole system again. Newton's divided differences fix both problems.

Concept 3 of 6

Newton's divided-difference interpolation

Build a small table. Each column is a “slope of slopes”. The numbers along the top diagonal become the coefficients of the polynomial.

pn(x) = f[x0] + f[x0,x1](x−x0) + f[x0,x1,x2](x−x0)(x−x1) + …

What it calculates: the unique polynomial through your n+1 points, in a nested form that is cheap to extend. When to use it: whenever a question says “using Newton's divided difference method” or gives a table of (x, f(x)).

xif[·]1st divided diff2nd divided diff3rd divided diff
x0f0
x1f1(f1−f0)/(x1−x0)
x2f2(f2−f1)/(x2−x1)(f[x1,x2] − f[x0,x1])/(x2−x0)
x3f3(f3−f2)/(x3−x2)(f[x2,x3] − f[x1,x2])/(x3−x1)(f[x1,x2,x3] − f[x0,x1,x2])/(x3−x0)
f[xi]just the function value fi (the “zeroth” difference)
f[xi,xi+1]the slope between two points — rise over run
f[xi,…,xi+k]how fast that slope itself is changing (curvature, third-order wiggle …). Denominator = the outermost x-values of that block (xi+k − xi), not the neighbouring gap — a classic slip
(x − x0)(x − x1)…the “switch” factors: each new term vanishes at all the earlier points, so adding it never disturbs what is already right
AnalogyThink of building a tower floor by floor. The first term is the ground floor (just the starting value). Each new point adds one more floor whose job is only to fix the error at that new point, without touching floors below. If you decide later to add a fourth point, you build one more floor — you do not demolish the tower.
Worked example (from the lecture) — try it first: interpolate f(x) = 1/x at x = 1, 2, 3
  1. Points: (1, 1), (2, 1/2), (3, 1/3).
  2. First differences: f[1,2] = (1/2 − 1)/(2−1) = −1/2; f[2,3] = (1/3 − 1/2)/(3−2) = −1/6.
  3. Second difference: f[1,2,3] = (−1/6 − (−1/2))/(3−1) = (1/3)/2 = 1/6.
  4. p2(x) = 1 − (1/2)(x−1) + (1/6)(x−1)(x−2) = x²/6 − x + 11/6.

Newton divided differencesf(x) = 1/x

Using Newton's divided difference method, derive the second-degree polynomial that interpolates f(x) = 1/x at x0 = 1, x1 = 2, x2 = 3. (This is the same exercise shown as a class example in the Week 7 lecture slides, labelled as a Sem 2 2025-26 final question.)

Try it yourself first, then reveal the solution
Solution
  1. Values: f(1) = 1, f(2) = 1/2, f(3) = 1/3.
  2. First differences: f[1,2] = (1/2 − 1)/(2 − 1) = −1/2; f[2,3] = (1/3 − 1/2)/(3 − 2) = −1/6.
  3. Second difference: f[1,2,3] = (−1/6 − (−1/2))/(3 − 1) = (1/3)/2 = 1/6.
  4. Polynomial: p2(x) = 1 − (1/2)(x − 1) + (1/6)(x − 1)(x − 2).
  5. Expanded (if asked): (1/6)(x² − 3x + 2) − x/2 + 1/2 + 1 = x²/6 − x + 11/6.
  6. Quick check: p2(2) = 4/6 − 2 + 11/6 = 0.5 ✓; p2(3) = 9/6 − 3 + 11/6 = 0.3333 ✓.

The slides' follow-ups for this same function: error bound at x = 2.5 is 0.375, the actual error is |0.4 − 0.375| = 0.025 (see Week 7).

Try it yourself first, then reveal the solution
Solution

What it's asking: build the divided-difference table. The big payoff of Newton's method: adding a point only adds one new term — you never redo the old ones.

  1. Table:
    xf1st diff2nd diff3rd diff
    −12
    20(0−2)/(2+1) = −2/3
    31(1−0)/(3−2) = 1(1+2/3)/(3+1) = 5/12
    43/2(3/2−1)/(4−3) = 1/2(1/2−1)/(4−2) = −1/4(−1/4−5/12)/(4+1) = −2/15

  3. (ii) Build on it: only the new bottom row was computed; the new term is the third difference times (x+1)(x−2)(x−3):

Concept 4 of 6

How big can the error be?

The polynomial matches f exactly at the data points, but between and beyond them there is an error. The lecture gives a guaranteed upper bound:

|f(x) − pn(x)| ≤ (1/(n+1)!) · ∏k=0..n |x − xk| · maxξ |f(n+1)(ξ)|
ndegree of the polynomial (number of points minus 1)
(n+1)!factorial of the next degree — bigger n shrinks the bound (good)
∏|x−xk|multiply the distances from your x to every data point — small when x is close to the points, zero when x equals one of them
f(n+1)the (n+1)th derivative of the true function; take its largest absolute value over ξ between min and max of {x, x0,…,xn}

Three lessons the slides draw out: (1) a higher degree can help (the 1/(n+1)! term); (2) being close to the data points makes the error small, and exactly zero at them; (3) outside the data range the product term explodes — extrapolation is dangerous.

Worked example (lecture) — error of the 1/x parabola at x = 2.5
  1. n = 2 so we need f″′ = f′′′: f(x) = x−1 ⇒ f′′′(x) = −6x−4.
  2. ξ lies in [1, 3] (min and max of 2.5, 1, 2, 3). max|f′′′| = max 6/x4 = 6 (at x = 1).
  3. Bound = (1/3!)|2.5−1||2.5−2||2.5−3|·6 = (1/6)(1.5)(0.5)(0.5)(6) = 0.375.
  4. Actual error: f(2.5) = 0.4; p2(2.5) = 2.5²/6 − 2.5 + 11/6 = 0.375; error = 0.025 — comfortably under the bound, as it must be. (Bounds are safe, not tight.)

Concept 5 of 6

Fixed-point iteration: solving equations by repeating a step

Idea: rewrite the equation f(x) = 0 as x = g(x). Pick a start x0, then keep feeding the output back in: x1 = g(x0), x2 = g(x1), … If the numbers settle down to a value, that value x* satisfies x* = g(x*) — a fixed point of g — and therefore f(x*) = 0.

AnalogyType any number into a calculator in radian mode and press cos over and over. The display wanders and then locks onto 0.739085… — the number that cos leaves unchanged. That locked value is the fixed point of cos. Fixed-point iteration is exactly this, applied to your own g.

The lecture's 4-step recipe (memorise this order):

  1. Find an interval [a, b] containing a root: check f(a)·f(b) < 0 (a continuous function that changes sign must cross zero).
  2. Rewrite as x = g(x) (the question often gives the g to use as a hint).
  3. Check convergence: g must keep x inside [a, b], and max |g′(x)| < 1 on [a, b].
  4. Iterate xn+1 = g(xn) from x0 (next section: when to stop).
g(x)the “feed-back” rule. Many different g's can come from the same f — some converge, some blow up
|g′|<1the slope of g is the shrink factor per step: if each step multiplies your error by a number below 1 the error melts; above 1, it grows. See the cobweb picture below
[a, b]the safety box: iterates must never leave it (otherwise the slope check no longer applies)
Worked example (lecture) — solve x − ½cos x = 0 on [0, π/2] using g(x) = ½cos x, x0 = 0
  1. f(0) = −0.5 < 0, f(π/2) = 1.571 > 0 ⇒ root in [0, π/2].
  2. g(x) = ½cos x; |g′(x)| = ½|sin x| ≤ 0.5 < 1 ✓ converges.
  3. x1 = 0.5, x2 = 0.43879, x3 = 0.45263, x4 = 0.44965, x5 = 0.45030, x6 = 0.45016 — the values wobble in smaller and smaller steps toward 0.450.

Tests: Wk 7 fixed-point iteration · Wk 7 stop condition  |  see it in the exam bank
fixed-point iterationexistence + convergence proofhow many d.p. correct

Consider x³ − 1 = 2 cos x on [π/4, π/2]. (i) Show there is at least one solution; show it can be written x = (1 + 2cos x)1/3; with g(x) = (1 + 2cos x)1/3, prove xn+1 = g(xn) converges to a solution. (ii) Use the method with x0 = 1.17, calculate up to x3. To how many decimal places is x3 correct?

Try it yourself first, then reveal the solution
Solution

What it's asking: the standard 4-part fixed-point recipe: (1) sign change ⇒ a root exists; (2) rearrange to x = g(x); (3) check g stays inside the interval and |g′| < 1; (4) iterate and test the stop condition.

  1. Root exists: f(x) = x³ − 1 − 2cos x. f(π/4) = 0.4845 − 1 − 1.4142 = −1.930 < 0; f(π/2) = 3.8758 − 1 − 0 = 2.876 > 0. f is continuous and changes sign ⇒ at least one root in [π/4, π/2].
  2. Rewrite: x³ = 1 + 2cos x ⇒ x = (1 + 2cos x)1/3 = g(x) ✓.
  3. g maps the interval into itself: g(π/4) = 2.4141/3 = 1.3415 and g(π/2) = 1; g is decreasing, so g([π/4, π/2]) = [1, 1.3415] ⊂ [0.785, 1.571] ✓.
  4. Slope condition: g′(x) = −(2/3) sin x (1 + 2cos x)−2/3. |g′| grows with x on this interval (sin x increases, (1+2cos x)−2/3 increases), so max|g′| = |g′(π/2)| = 2/3 < 1 ⇒ the iteration converges to the root.
  5. Iterate: x0 = 1.17 → x1 = g(1.17) = 1.21199; x2 = 1.19403; x3 = 1.20181.
  6. Accuracy: m = min|f′| = min(3x² + 2 sin x) = f′(π/4) = 3.2648. |f(x3)|/m = 0.00444. Since 0.00444 < 0.5×10−2 = 0.005 but not < 0.0005, x3 is correct to 2 decimal places (root ≈ 1.20).
Concept 6 of 6

When to stop: the stop condition for “K correct decimals”

“It looks like it has settled” is not good enough for an exam. The slides give a precise test using how steep f is.

m = min[a,b] |f′(x)|    stop when   |f(xn)| / m  <  ½ × 10−K
mthe smallest steepness of f on the interval (find the minimum of |f′|; often at an endpoint)
|f(xn)|how far f is from zero at your current guess — the “residual”
Knumber of correct decimal places wanted (2 d.p. ⇒ ½×10−2 = 0.005; 3 d.p. ⇒ 0.0005)
Analogy (why this works)Imagine walking down a hill whose slope is never gentler than m. If you are at height h above sea level, the sea (the root, where f = 0) can't be farther than h/m metres away horizontally — a gentler slope could be farther, but m is the gentlest it ever gets. So |f(xn)|/m is a guaranteed upper bound on your distance from the root.
Worked example (lecture) — the same equation to 2 decimal places
  1. f(x) = x − ½cos x, f′(x) = 1 + ½ sin x, so m = min over [0, π/2] = f′(0) = 1.
  2. n=0: x = 0, |f|/m = 0.5. n=1: x = 0.5, 0.0612. n=2: x = 0.43879, 0.0138. n=3: x = 0.45263, 0.00298 < 0.005 ✓ stop.
  3. Answer: x ≈ 0.45 (correct to 2 d.p.).

Solve x²ex = 1 on x ∈ [0.5, 1] to 3 decimal places. (Hint: g(x) = e−x/2.)

Try it yourself first, then reveal the answer
Answer
  1. f(x) = x²ex − 1. f(0.5) = −0.588 < 0, f(1) = 1.718 > 0 ⇒ root in [0.5, 1]. (x²ex = 1 ⇔ xex/2 = 1 ⇔ x = e−x/2.)
  2. g′(x) = −½e−x/2, |g′| ≤ 0.389 < 1 ✓; g(0.5) = 0.779, g(1) = 0.607 stay in [0.5, 1] ✓.
  3. f′(x) = ex(x² + 2x), increasing ⇒ m = f′(0.5) = 2.0609. Target |f|/m < 0.0005.
  4. x0 = 0.5 (0.2852); x1 = 0.77880 (0.1560); x2 = 0.67746 (0.0468); x3 = 0.71267 (0.0174); x4 = 0.70024 (0.0060); x5 = 0.70461 (0.0021); x6 = 0.70307 (0.00075); x7 = 0.70361 (0.00026 < 0.0005 ✓).
  5. Answer: x ≈ 0.703 (key). Honest note: x7 = 0.70361 would round to 0.704, but the stop condition only says the root lies within 0.00026 of x7, i.e. in (0.7033, 0.7039). Consider 2sin²x − x²/2 + 5/2 = 0 on [π/2, π]. (i) Show a root exists. (ii) What conditions guarantee convergence of xn+1 = g(xn)? (iii) It can be written x = (4sin²x + 5)1/2 ≡ g1(x) or x = (4sin²x + 5)/x ≡ g2(x). Which converges? Compute an approximate solution, with a criterion for 2 d.p., starting at x0 = 2.53.

Try it yourself first, then reveal the solution
Solution
  1. (i) Root exists: h(x) = 2sin²x − x²/2 + 2.5. h(π/2) = 2 − 1.2337 + 2.5 = 3.266 > 0; h(π) = 0 − 4.9348 + 2.5 = −2.435 < 0 ⇒ sign change ⇒ a root in [π/2, π].

✍️ Write This Down

Copy these into your own notes:

  • n + 1 points ⇒ unique polynomial of degree ≤ n. Newton table: slopes, slopes of slopes…; take the top diagonal; the denominator of each column spans the outermost x's of that block.
  • Adding a point = add one new bottom row + one new term × (x−x0)…(x−xn). Old terms never change.
  • Error bound: |f(x) − pn(x)| ≤ (1/(n+1)!)∏|x−xk| max|f(n+1)(ξ)| — zero at data points, huge outside the data range.
  • Fixed-point recipe: (1) f(a)f(b)<0, (2) x = g(x), (3) g stays in [a,b] and max|g′|<1, (4) iterate; if |g′| > 1 try another rearrangement (the 2024-25 final's g2 diverged).
  • Stop for K decimals: m = min|f′|; stop when |f(xn)|/m < ½×10−K (2 d.p. → 0.005, 3 d.p. → 0.0005).
  • n significant digits ⇔ relative error < ½×101−n.
  • Exam habit: always write the sign-change check and the |g′| check, even if the numbers are the easy part — they are separate marks.

👁️ Visualize It

A cobweb diagram shows what fixed-point iteration does. Start at x0 on the axis, go up to the curve y = g(x) (that gives g(x0)), then sideways to the diagonal y = x (that turns the output into the next input), then up again, and so on.

g(x) = ½cos x from x0 = 0. The green staircase spirals into the red point where the curve crosses the diagonal. It converges because the curve is gentle there (|g′| < 1). If the curve were steeper than the diagonal at the crossing (|g′| > 1) the staircase would spiral outward — that is the diverging case the exam warns about.
