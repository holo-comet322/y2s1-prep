Concept 1 of 3

Classifying a PDE (the 5-question checklist)

A PDE has an unknown function of two or more variables and partial derivatives (ux, uxy…). If the unknown depends on just one variable it is an ODE.

QuestionHow to decide
Orderthe highest derivative that appears (uxx → 2; a third derivative → 3). A product of lower derivatives does not raise the order.
Linear?u and its derivatives appear only to the first power, never multiplied together or inside sin/eu/squares. Coefficients may depend on x, y, t only.
Variant / invariantinvariant if the coefficients of u and its derivatives are constants; variant if any of them depends on the independent variables (e.g. y²uxx, x²Ryyy).
Homogeneous?after moving everything to one side, there is no term free of u. A leftover term like x, y or x ey makes it non-homogeneous.
AnalogyLinear = a recipe where doubling the ingredients doubles the dish. Non-linear = ingredients interact (a product u·ux), so doubling does something unpredictable.
Tutorial 12 Q1 — the five equations
  • (a) ux+uy = uxuy: 1st order, PDE, non-linear (uxuy is a product), invariant (constant coefficients), homogeneous (every term contains u).
  • (b) uxx+u+xey = 0: 2nd order, PDE, linear, invariant, non-homogeneous (the term xey has no u).
  • (c) ux+3uy+3x cos(xy) = −y²uxx: 2nd order, PDE, linear, variant (coefficient y² of uxx depends on y), non-homogeneous (3x cos xy).
  • (d) uxx+u+x = 0: 2nd order, linear, invariant, non-homogeneous. Only x derivatives appear, so if u depends on x alone it is really an ODE — say which assumption you use.
  • (e) uxx+u+y = 0: same, but the y in the free term means u depends on y too, so treat it as a PDE; non-homogeneous.
Concept 2 of 3

Checking that a function is a solution

  1. Compute every derivative that appears in the PDE (chain rule!).
  2. Substitute into the PDE and simplify; both sides should match for all x, t.
  3. If constants are unknown (find a, b, c²), group by independent functions (e.g. eax and e−bx) and set each bracket to zero.
Tutorial 12 Q4: show u = F(2x+5t) + G(2x−5t) solves 4utt = 25uxx
  1. Chain rule: ux = 2F′ + 2G′, uxx = 4F″ + 4G″.
  2. ut = 5F′ − 5G′, utt = 25F″ + 25G″.
  3. 4utt = 100(F″+G″) and 25uxx = 100(F″+G″). Equal for any F, G ✓ — a wave travelling at speed 5/2 each way.
Concept 3 of 3

Direct integration (uxy = f(x, y))

  1. Integrate with respect to one variable; the “constant” is an arbitrary function of the other variable (g(y) or h(x)).
  2. Integrate again w.r.t. the other variable: general solution u = (double integral) + G(x) + H(y).
  3. Apply the two conditions; each fixes one arbitrary function (e.g. G(x) from u(x,0)). The stray constants such as H(0) always cancel.
AnalogyUndoing a double derivative leaves two unknowns, like two lost keys: one belongs to the x-door (a function of x), the other to the y-door. Each boundary condition is a clue to finding one key.
Tutorial 12 Q2: uxy = 2xey, u(0,y) = y, u(x,0) = x
  1. Integrate in x: uy = x²ey + g(y). Integrate in y: u = x²ey + G(y) + h(x).
  2. u(0,y) = y: G(y) + h(0) = y ⇒ G(y) = y − h(0).
  3. u(x,0) = x: x² + G(0) + h(x) = x with G(0) = −h(0) ⇒ h(x) = x − x² + h(0).
  4. u = x²ey + y + x − x² (constants cancel). Check u(0,y)=y ✓, u(x,0)=x²+x−x²=x ✓.
Tutorial 12 Q3: zxy = x²y, z(x,0) = x², z(1,y) = cos y
  1. Integrate in y: zx = x²y²/2 + g(x); in x: z = x³y²/6 + G(x) + h(y).
  2. z(x,0) = x²: G(x) + h(0) = x². z(1,y) = cos y: y²/6 + G(1) + h(y) = cos y.
  3. So G(x) = x² − h(0), h(y) = cos y − y²/6 − G(1), with G(1)+h(0) = 1 ⇒ the constants sum to −1.
  4. z = x³y²/6 + x² + cos y − y²/6 − 1 (matches the printed answer).

classify PDEslinear / order / varianthow to test linearity

(a) How would you determine whether a PDE is linear? (b) State whether each is linear/non-linear, its order, and whether invariant or variant: (i) ∂u/∂t = 4∂²u/∂x²; (ii) x²∂³R/∂y³ = y³∂²R/∂x²; (iii) (∂z/∂u)² + (∂z/∂v)² = 1.

Try it yourself first, then reveal the solution
Solution
  1. (a) Linearity test: a PDE is linear if the unknown function and each of its partial derivatives appear only to the first power, are not multiplied together, and are not inside nonlinear functions (sin u, eu, u²). Coefficients may depend on the independent variables (x, y, t) but not on u or its derivatives. Otherwise it is non-linear. (Equivalent test: the sum of two solutions is also a solution.)
  2. Order = highest derivative that appears. Invariant = coefficients are constants; variant = at least one coefficient depends on the independent variables.
  3. (i) ut = 4uxx: 2nd order, linear, invariant (constant coefficient 4) — the heat equation.
  4. (ii) x²Ryyy = y³Rxx: 3rd order, linear (R and derivatives are to the first power) and variant (coefficients x², y³ depend on x and y).
  5. (iii) (zu)² + (zv)² = 1: 1st order, non-linear (derivatives are squared), coefficients are constants (invariant).

classifyverify a solutionfind c²

Ut(t,x) = c²Uxx(t,x), c constant. (i) State order; linear/nonlinear; variant/invariant; homogeneous/non-homogeneous. (ii) Show U(t,x) = e−π²tcos(25x) is a solution and give c².

Try it yourself first, then reveal the solution
Solution
  1. (i) Highest derivative is Uxx ⇒ 2nd order. Linear. Constant coefficient c² ⇒ invariant. Writing it as Ut − c²Uxx = 0 (nothing left over) ⇒ homogeneous.
  2. (ii) Substitute: Ut = −π² e−π²tcos 25x = −π²U. Ux = −25 e−π²tsin 25x; Uxx = −625 e−π²tcos 25x = −625U.
  3. Plug into the PDE: −π²U = c²(−625U) ⇒ c² = π²/625 (c = π/25 ≈ 0.1257). Both sides match for every (t,x), so U is a solution for this c.

find constants so u satisfies the PDE

Find positive constants a and b such that u(x,t) = e−6t(eax + e−bx) satisfies ut + ux + uxx = 0.

Try it yourself first, then reveal the solution
Solution
  1. Differentiate: ut = −6u; ux = e−6t(aeax − be−bx); uxx = e−6t(a²eax + b²e−bx).
  2. Add up and group by the independent exponentials: e−6t[ eax(−6 + a + a²) + e−bx(−6 − b + b²) ] = 0.
  3. eax and e−bx are independent functions, so each bracket must vanish: a² + a − 6 = 0 ⇒ (a + 3)(a − 2) = 0; b² − b − 6 = 0 ⇒ (b − 3)(b + 2) = 0.
  4. Positive roots: a = 2, b = 3.

direct integration (mixed derivative)general + particular solution

yxt = 3x²e−t + sin t. (i) Find the general solution. (ii) With y(0,t) = t² and y(x,0) = sin x, find the solution.

Try it yourself first, then reveal the solution
Solution

What it's asking: ∂²y/∂x∂t means “differentiate in x then t”, so undo it by integrating in x then t. Each integration leaves an arbitrary function of the other variable.

  1. Integrate in x: yt = x³e−t + x sin t + g(t) (g(t) = constant w.r.t. x).
  2. Integrate in t: y = −x³e−t − x cos t + G(t) + H(x) — the general solution (G, H arbitrary functions).
  3. Use y(0,t) = t²: −0 − 0 + G(t) + H(0) = t² ⇒ G(t) = t² − H(0).
  4. Use y(x,0) = sin x: −x³ − x + G(0) + H(x) = sin x ⇒ H(x) = sin x + x³ + x − G(0), and G(0) = −H(0).
  5. Combine (the constants H(0) and G(0) cancel):
    y(x,t) = x³(1 − e−t) + x(1 − cos t) + t² + sin x
    Check: y(0,t) = t² ✓; y(x,0) = sin x ✓; yxt = 3x²e−t + sin t ✓.

direct integrationgeneral + particular solution

yxt = te−x + e−t. (i) Find the general solution. (ii) With y(0,t) = ½t² and y(x,0) = −x, find the solution.

Try it yourself first, then reveal the solution
Solution
  1. Integrate in x: yt = −te−x + xe−t + g(t).
  2. Integrate in t: y = −(t²/2)e−x − xe−t + G(t) + H(x) (general solution).
  3. y(0,t) = ½t²: −t²/2 − 0 + G(t) + H(0) = t²/2 ⇒ G(t) = t² − H(0).
  4. y(x,0) = −x: 0 − x + G(0) + H(x) = −x ⇒ H(x) = −G(0) = H(0) (a constant).
  5. Combine:
    y(x,t) = −(t²/2)e−x − xe−t + t²
    Check: y(0,t) = −t²/2 + t² = t²/2 ✓; y(x,0) = −x ✓; yxt = te−x + e−t ✓.

Final 2025-26 Sem 1 · Q4(a) · 12 marks
Tests: Wk 12 direct integration  |  see it in the exam bank
direct integrationu(x,0), u(0,y) conditions

Solve uxy = x² + x cos y by direct integration, with u(x,0) = x and u(0,y) = 0.

Try it yourself first, then reveal the solution
Solution
  1. Integrate in x: uy = x³/3 + (x²/2)cos y + g(y).
  2. Integrate in y: u = x³y/3 + (x²/2)sin y + G(y) + h(x).
  3. u(0,y) = 0: 0 + 0 + G(y) + h(0) = 0 ⇒ G(y) = −h(0) (a constant).
  4. u(x,0) = x: 0 + 0 + G(0) + h(x) = x ⇒ h(x) = x + h(0). The constants cancel: G + h(x) = x.
  5. u(x,y) = x³y/3 + (x²/2) sin y + x. Check: u(x,0) = x ✓; u(0,y) = 0 ✓; uxy = x² + x cos y ✓.

✍️ Write This Down

Copy these into your notes:

  • Classify: order (highest derivative), linear (no products/powers of u), invariant (constant coefficients), homogeneous (no u-free term).
  • Verify solution: differentiate, substitute, both sides equal; with unknown constants, group independent exponentials and zero each bracket.
  • Direct integration: integrate each variable once; arbitrary functions, not constants; use both conditions; stray constants cancel; always check both conditions.
  • d’Alembert: u = F(x+ct) + G(x−ct) solves utt = c²uxx.
