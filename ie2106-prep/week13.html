📡 Exam radar — Week 13
  • Part (b) of the PDE question is usually a method-of-solution question: separation of variables (5 of 6 finals), with the heat/wave equation + boundary conditions in 2024-25 S1 and 2025-26 S1, and Laplace transform for a PDE in 2024-25 S2. Know the template cold.
  • The recurring structure: assume u = X(x)T(t) → divide → both sides equal a constant → two ODEs → use conditions → superposition. The sign of the separation constant (−λ) is chosen so the time part decays (heat) or oscillates (wave).
  • Trick that appears: equations with x·yx + t·yt = 0 (2023-24 S2) separate into powers xk, t−k, not exponentials.

Concept 1 of 3

Separation of variables: the template

  1. Assume u(x,t) = X(x)T(t).
  2. Substitute and divide so that all x-stuff is on one side and all t-stuff is on the other.
  3. A function of x alone equals a function of t alone only if both equal a constant (the separation constant, k or −λ).
  4. Solve the two ODEs, multiply back, and use the initial/boundary conditions to fix constants.
AnalogyLike a spreadsheet where row effects and column effects multiply: the value in each cell is (row factor)×(column factor). Separation says the solution has that shape, which turns one hard 2D problem into two easy 1D ones.
Tutorial 13 Q1: ux = t ut ⇒ u = Keλxtλ
  1. X′T = tXT′; divide by XT: X′/X = tT′/T = λ.
  2. X′ = λX ⇒ X = Aeλx. T′/T = λ/t ⇒ ln T = λ ln t ⇒ T = Btλ.
  3. u = Keλxtλ with K = AB.

Tutorial 13 Q2: ut = 2uxx, 0<x<3, ends 0, u(x,0) = 5sin4πx − 3sin8πx + 2sin10πx
  1. (a) With u = XT: T′/(2T) = X″/X = −λ; conditions X(0) = X(3) = 0; boundedness chooses λ > 0.
  2. (b) X = sin(√λ x) with √λ·3 = nπ ⇒ √λ = nπ/3. The profile has sin 4πx = sin(12πx/3), sin 8πx (n = 24), sin 10πx (n = 30).
  3. Each mode decays as exp(−2(√λ)²t) = exp(−2(4π)²t) = e−32π²t, and similarly 128π² for 8π, 200π² for 10π.
  4. u = 5e−32π²tsin4πx − 3e−128π²tsin8πx + 2e−200π²tsin10πx.
Concept 3 of 3

Laplace transform for PDEs

Transform with respect to t; x is just a parameter, so the PDE becomes an ODE in x. Initial conditions in t enter automatically: L{ut} = sU − u(x,0); L{utt} = s²U − su(x,0) − ut(x,0). Solve the ODE in x, apply the x-conditions, then invert in t.

Works when coefficients of the derivatives in t are constant (Tutorial 13 Q4(b)): x²yt is fine; t·yx is not, because multiplying by t becomes a derivative in s (−d/ds), which makes the problem harder instead of easier (Q4(c)).

Tutorial 13 Q3: utt = uxx, u(0,t)=u(1,t)=0, u(x,0)=0, ut(x,0)=sinπx
  1. Transform in t: s²U − sin πx = Uxx ⇒ Uxx − s²U = −sinπx.
  2. Try U = A sinπx: −π²A − s²A = −1 ⇒ A = 1/(s²+π²). It satisfies U(0)=U(1)=0 (add no homogeneous solution).
  3. Invert: L−1{1/(s²+π²)} = sinπt/π. u = (1/π) sinπt sinπx.
Tutorial 13 Q4(a): yx − x²yt = 0, y(x,0)=0, y(0,t)=u(t)
  1. Transform in t: Yx = x²sY (initial value 0). Solve: Y = C(s)esx³/3.
  2. Y(0,s) = 1/s ⇒ C = 1/s. So Y = esx³/3/s.
  3. Invert (advance, not delay, because the exponent is +): y = u(t + x³/3).

separation of variables, 1st order two variablesfit initial condition

Solve ∂u/∂x = 2∂u/∂y + u with u(x,0) = 3e−5x by separation of variables.

Try it yourself first, then reveal the solution
Solution

What it's asking: assume the answer factorises as u = X(x)Y(y), so the PDE splits into two ordinary ODEs tied together by a separation constant k.

  1. u = XY ⇒ X′Y = 2XY′ + XY. Divide by XY: X′/X = 2Y′/Y + 1 = k (left depends only on x, right only on y ⇒ both equal a constant).
  2. X′ = kX ⇒ X = Aekx. 2Y′/Y + 1 = k ⇒ Y′/Y = (k−1)/2 ⇒ Y = Be(k−1)y/2.
  3. u = C ekx + (k−1)y/2.
  4. Initial condition: u(x,0) = Cekx = 3e−5x ⇒ k = −5, C = 3.
  5. u(x,y) = 3e−5x − 3y ((k−1)/2 = −3). Check: ux = −5u; 2uy + u = −6u + u = −5u ✓.

separation of variables with variable coefficientsparticular solution

Solve x·yx + t·yt = 0 by separation of variables. Find the particular solution if y(x,1) = x and y(1,t) = t−1.

Try it yourself first, then reveal the solution
Solution
  1. y = X(x)T(t): x X′T + t X T′ = 0. Divide by XT: xX′/X = −tT′/T = k.
  2. xX′ = kX ⇒ X = Axk (separable: dX/X = k dx/x). −tT′ = kT ⇒ T = Bt−k.
  3. General: y = C xk t−k = C(x/t)k.
  4. y(x,1) = x: Cxk = x ⇒ k = 1, C = 1.
  5. Particular solution: y = x/t. Check y(1,t) = 1/t ✓ (the second condition is satisfied automatically).

wave equation by separationDirichlet BConly one initial condition given

Utt = 4Uxx, U(t,0) = U(t,π) = 0 for all t, U(0,x) = sin 2x. Find the general solution by separation of variables.

Try it yourself first, then reveal the solution
Solution
  1. U = T(t)X(x): T″X = 4TX″ ⇒ T″/(4T) = X″/X = −λ.
  2. Space part with BCs: X″ + λX = 0, X(0) = X(π) = 0. Non-trivial solutions need λ = n² (n = 1, 2, …) with Xn = sin nx.
  3. Time part: T″ = −4n²T ⇒ Tn = Ancos 2nt + Bnsin 2nt.
  4. General solution: U(t,x) = Σn≥1 sin(nx)[Ancos 2nt + Bnsin 2nt].
  5. Use U(0,x) = sin 2x: Σ An sin nx = sin 2x ⇒ A2 = 1, all other An = 0.
  6. Result: U = sin 2x (cos 4t + B2 sin 4t) + Σn≠2 Bn sin nx sin 2nt. Only one initial condition is given (nothing about Ut(0,x)), so the Bn stay free; with the usual “starts at rest” condition Ut(0,x) = 0 all Bn = 0 and U(t,x) = sin 2x cos 4t. Check: Utt = −16 sin 2x cos 4t; 4Uxx = 4(−4)sin 2x cos 4t ✓.

separation of variablesLaplace transform method for a PDE

∂y/∂x + 2∂y/∂t = 0. (i) Solve for y(x,t) by separation of variables. (ii) Solve using the Laplace transform (in t), with y(0,t) = u(t) and y(x,0) = 0 for x > 0.

Try it yourself first, then reveal the solution
Solution
  1. (i) Separation: y = X(x)T(t): X′T + 2XT′ = 0 ⇒ X′/X = −2T′/T = k. X = Aekx; T′ = −(k/2)T ⇒ T = Be−kt/2. y = Cek(x − t/2) (and any sum of such terms — the solution is a wave moving in x at speed ½).
  2. (ii) Transform in t (x is just a parameter): Y(x,s) = Lt{y}. L{yt} = sY − y(x,0) = sY. The PDE becomes the ODE in x: dY/dx + 2sY = 0 ⇒ Y = A(s)e−2sx.
  3. Boundary condition at x = 0: Y(0,s) = L{u(t)} = 1/s ⇒ A(s) = 1/s. So Y(x,s) = e−2sx/s.
  4. Invert (time-shift by 2x): y(x,t) = u(t − 2x): zero until t = 2x, then 1 — a step that travels along x at speed 1/2. Check: yx + 2yt = −2δ(t−2x) + 2δ(t−2x) = 0 ✓; y(0,t) = u(t) ✓; y(x,0) = 0 for x > 0 ✓.

heat equation by separationmatch to the initial profile

Solve ut = uxx by separation of variables, with u(x,0) = cos 4x.

Try it yourself first, then reveal the solution
Solution
  1. u = X(x)T(t): X T′ = X″ T ⇒ T′/T = X″/X = −λ (choose the minus sign: heat dies away with time, so we expect decaying T).
  2. T′ = −λT ⇒ T = e−λt. X″ + λX = 0 ⇒ X = a cos(√λ x) + b sin(√λ x).
  3. Match the initial profile: u(x,0) = X(x) must equal cos 4x ⇒ √λ = 4 (λ = 16), a = 1, b = 0.
  4. u(x,t) = e−16t cos 4x. Check: ut = −16u; uxx = −16u ✓; u(x,0) = cos 4x ✓.

Pattern: when the initial condition is a single sine/cosine, pick λ so the space part reproduces it — no Fourier series is needed.

✍️ Write This Down

Copy these into your notes:

  • u = XT → divide → both sides = constant. Heat: T decays; wave: T oscillates.
  • Ends fixed on [0,L]: Xn = sin(nπx/L), λn = (nπ/L)².
  • Heat: each mode multiplied by exp(−k(nπ/L)²t). Match sine coefficients to u(x,0).
  • Laplace for PDE: transform in t; solve the resulting ODE in x; apply x-conditions; invert.
  • Equation like x yx + t yt = 0 gives powers xkt−k.
