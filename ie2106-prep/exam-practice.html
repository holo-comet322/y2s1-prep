pdf constantE[g(X)]Var[g(X)]
Method: Area = 1 for constants; E[g(X)] = ∫g f; Var = E[g²] − E[g]²
Concept: Wk 1–2 probability & random variables

Let X have pdf f(x) = ex for 0 < x < p (0 otherwise), where p > 0 is a constant. Find p. Hence compute E(eX/2 + 1) and Var(eX/2 + 1).

Try it yourself first, then reveal the solution
Solution

What it's asking: (1) a pdf must have total area 1 → that pins down p. (2) To get the average of a function of X you don't need the pdf of that function — you just weigh the function by the original pdf.

∫ f(x) dx = 1   |   E[g(X)] = ∫ g(x) f(x) dx   |   Var(g) = E[g²] − (E[g])²   |   Var(g + c) = Var(g)
  1. Find p: ∫0p ex dx = ep − 1 = 1 ⇒ ep = 2 ⇒ p = ln 2 ≈ 0.6931.
  2. Mean of eX/2: E(eX/2) = ∫0ln 2 ex/2·ex dx = ∫ e3x/2 dx = (2/3)(23/2 − 1) = (2/3)(1.828427) = 1.218951. So E(eX/2 + 1) = 2.2190 (adding 1 just shifts the mean by 1).
  3. Second moment: E[(eX/2)²] = E(eX) = ∫0ln 2 e2x dx = (1/2)(e2 ln 2 − 1) = (1/2)(4 − 1) = 1.5.
  4. Variance: Var(eX/2) = 1.5 − (1.218951)² = 1.5 − 1.485843 = 0.014157. The "+1" does not change spread, so Var(eX/2 + 1) = 0.0142.

Exam tip: whenever you see "E(some function of X)", write the integral of (function × pdf) straight away. Constants added to X shift E but never Var; constants multiplied scale E by k and Var by k².

Solution

What it's asking: a normal two-tail t-test, then two “reverse-engineering” questions: first move α, then move μ0, and ask where the decision stays the same.

Solve ut = uxx by separation of variables, with u(x,0) = cos 4x.

Try it yourself first, then reveal the solution
Solution
  1. u = X(x)T(t): X T′ = X″ T ⇒ T′/T = X″/X = −λ (choose the minus sign: heat dies away with time, so we expect decaying T).
  2. T′ = −λT ⇒ T = e−λt. X″ + λX = 0 ⇒ X = a cos(√λ x) + b sin(√λ x).
  3. Match the initial profile: u(x,0) = X(x) must equal cos 4x ⇒ √λ = 4 (λ = 16), a = 1, b = 0.
  4. u(x,t) = e−16t cos 4x. Check: ut = −16u; uxx = −16u ✓; u(x,0) = cos 4x ✓.

Pattern: when the initial condition is a single sine/cosine, pick λ so the space part reproduces it — no Fourier series is needed.
