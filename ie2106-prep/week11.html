Concept 1 of 5

Transfer function: H(s) = Y(s)/X(s)

H(s) = Y(s)/X(s)  (all initial conditions = 0)  ⇒  Y(s) = H(s)X(s)
X(s)transform of the input x(t) (what you push in).
Y(s)transform of the output y(t) (what comes out).
H(s)the system's own “fingerprint”: it depends only on the ODE coefficients, not on what input you use. Once you have H, any input becomes one multiplication.
AnalogyH(s) is a recipe-converter: whatever ingredients X you feed in, the machine multiplies by the same H. A guitar amp has a fixed “tone”; the song changes, the tone H does not.

To get H from an ODE: transform with zero initial conditions and divide. For y″ + y = x: (s²+1)Y = X ⇒ H = 1/(s²+1) (this is 2023-24 S1 Q3(b)). The denominator is the characteristic polynomial; its roots are the poles that decide stability.

Concept 2 of 5

Impulse response h(t) and the convolution theorem

f(t)∗g(t) = ∫0t f(τ)g(t−τ)dτ    L{f∗g} = F(s)G(s)    L−1{F(s)G(s)} = f(t)∗g(t)

Since L{δ} = 1, feeding x = δ gives Y = H — so h(t) = L−1{H(s)} is the impulse response. For any input, y(t) = h(t)∗x(t): the output is the input “smeared” by the impulse response. Two ways to find y: (1) convolve in time (hard integral), or (2) multiply H·X in s and invert (usually easier — Tutorial 11 Q3(c)).

AnalogyHit a bell once (impulse): its ringing is h(t). A drum-roll of many hits (input x) gives a sum of overlapping, delayed rings — that sum is the convolution.
Tutorial 11 Q3(c): H(s) = 4/(s²+2s+5), x = u(t)
  1. (i) s²+2s+5 = (s+1)²+4 (a = 1, ω = 2). H = 2·2/((s+1)²+4) ⇒ h(t) = 2e−tsin 2t u(t).
  2. (ii) Y = H/s = 4/[s(s²+2s+5)] = (4/5)/s − (4/5)(s+2)/(s²+2s+5). Write s+2 = (s+1)+1: (s+1)/((s+1)²+4) → e−tcos 2t; 1/((s+1)²+4) = ½·2/(…) → ½e−tsin 2t.
  3. y(t) = [4/5 − (4/5)e−tcos 2t − (2/5)e−tsin 2t]u(t). Check y(0) = 4/5−4/5 = 0 ✓; settles to 4/5 = H(0).
Concept 3 of 5

Step response and what it tells you

Step response: x = u(t), so Y = H(s)/s. Two shortcuts that save time in exams:

  • Final value: if all poles of sY(s) are in the left half-plane, y(∞) = lims→0 sY(s) = H(0) for a unit step.
  • Going backwards: if the step response is given (2024-25 S1 Q3(b)), then H(s) = [step response transform] ÷ (1/s) = s·Ystep(s). E.g. y = (1−e−2t)u(t) ⇒ Y = 2/[s(s+2)] ⇒ H = 2/(s+2).
AnalogyFlip a light switch on a dimmer-with-delay lamp and watch how brightness climbs and settles — that curve is the step response; the level it settles at is H(0).

Circuits in the s-domain: components become impedances

ComponentTime laws-domain impedance
Resistorv = RiR
Inductorv = L di/dtsL
Capacitori = C dv/dt1/(sC)

With zero initial energy, treat them like resistors: series impedances add; I(s) = V(s)/Z(s). No differential equation needed.

Tutorial 11 Q2 — series R–C, switch closes at t = 0, input vin, output i
  1. Z(s) = R + 1/(sC) = (RCs+1)/(Cs). So H(s) = I/Vin = 1/Z = Cs/(RCs+1) (matches the printed answer).
  2. For a constant source V: Vin = V/s, so I(s) = CV/(RCs+1) = (V/R)/(s + 1/RC) ⇒ i(t) = (V/R)e−t/RCu(t): current starts at V/R and decays as the capacitor charges. (Assumes a DC source V; the figure was not available.)
Concept 5 of 5

Pulses & piecewise inputs through a system

  1. Write the input with steps (and ramps): a pulse 0→2 is u(t)−u(t−2); a ramp that stops at 1 is t u(t) − (t−1)u(t−1).
  2. Transform with the delay rule: (1−e−2s)/s, or (1−e−s)/s².
  3. Multiply by H(s). Do the partial fractions on the part without the exponentials, e.g. Q(s) = H(s)/s; then Y = (1 − e−2s)Q(s).
  4. Invert Q to q(t). Then y(t) = q(t)u(t) − q(t−2)u(t−2). Give the answer in pieces: for 0 ≤ t < 2 only the first term; for t ≥ 2 both.
AnalogyThe system sees “switch on” at 0 and “switch off” at 2. The response is the response to the first event, minus an identical copy that starts 2 seconds later.

transfer functionresponse to a rectangular pulse input

y″(t) + y(t) = x(t), t ≥ 0. (i) Find the transfer function. (ii) With zero initial conditions, find y(t) when x(t) is the pulse of height 1 from t = 0 to t = 2 (Figure 1).

Try it yourself first, then reveal the solution
Solution
  1. (i) Transfer function = output/input with zero initial conditions: (s² + 1)Y = X ⇒ H(s) = 1/(s² + 1).
  2. (ii) Input: x(t) = u(t) − u(t−2) ⇒ X(s) = (1 − e−2s)/s.
  3. Y(s) = H(s)X(s) = (1 − e−2s)/[s(s²+1)]. Partial fractions: 1/[s(s²+1)] = 1/s − s/(s²+1) ⇒ (1 − cos t)u(t).
  4. Delay the second piece: y(t) = (1 − cos t)u(t) − (1 − cos(t−2))u(t−2). So for 0 ≤ t < 2: y = 1 − cos t; for t ≥ 2 the two pieces combine: y = cos(t−2) − cos t.

transfer function from step responseramp-then-hold input

The unit-step response of a linear system is y(t) = (1 − e−2t)u(t). Find the transfer function and use it to find the response to x(t) = 0 (t<0); t (0 ≤ t ≤ 1); 1 (t > 1).

Try it yourself first, then reveal the solution
Solution
  1. Step response → H(s): Ystep = 1/s − 1/(s+2) = 2/[s(s+2)]. Since Xstep = 1/s: H(s) = Y/X = 2/(s+2).
  2. Write the input with steps: x(t) = t u(t) − (t−1)u(t−1) (ramp up to 1 at t = 1, then flat). X(s) = (1 − e−s)/s².
  3. Y(s) = H X = 2(1 − e−s)/[s²(s+2)]. Partial fractions of 2/[s²(s+2)] = −½/s + 1/s² + ½/(s+2) ⇒ q(t) = (−½ + t + ½e−2t)u(t).
  4. y(t) = q(t) − q(t−1)u(t−1). For 0 ≤ t < 1: y = −½ + t + ½e−2t. For t ≥ 1: y = 1 + ½e−2t − ½e−2(t−1).

Final 2025-26 Sem 2 · Q3(a) · 15 marks
Tests: Wk 11 circuits in the s-domain · Wk 11 transfer function  |  see it in the exam bank
RLC circuit transfer functionimpulse response (delta input)

A band-pass filter: series inductor L = 1 H, capacitor C = 1/1.01 F and resistor R = 0.2 Ω; input vin(t), output the loop current iout(t). (i) Derive H(s) = Iout(s)/Vin(s). (ii) Find iout(t) when vin(t) = δ(t).

Try it yourself first, then reveal the solution
Solution

What it's asking: in the s-domain every component becomes an impedance — inductor sL, capacitor 1/(sC), resistor R. In a series loop they simply add, and current = voltage/impedance.

  1. Total impedance: Z(s) = sL + R + 1/(sC) = s + 0.2 + 1.01/s = (s² + 0.2s + 1.01)/s.
  2. (i) Transfer function:
    H(s) = Iout/Vin = 1/Z(s) = s/(s² + 0.2s + 1.01)
  3. (ii) Delta input: L{δ(t)} = 1, so Iout(s) = H(s). Complete the square: s² + 0.2s + 1.01 = (s + 0.1)² + 1.
  4. s/[(s+0.1)²+1] = (s + 0.1)/[(s+0.1)²+1] − 0.1/[(s+0.1)²+1].
  5. iout(t) = e−0.1t[cos t − 0.1 sin t] u(t) — a decaying oscillation at ω = 1 rad/s (poles at −0.1 ± j1: stable, lightly damped).

✍️ Write This Down

Copy these into your notes:

  • H(s) = Y/X (zero initial conditions). Y = HX. h(t) = L−1{H}. Impulse input: Y = H.
  • f∗g ↔ FG. Step input X = 1/s, so Ystep = H/s ⇒ H = sYstep.
  • Impedances: R, sL, 1/(sC); series add; I = V/Z. RC series: Hi/v = Cs/(RCs+1).
  • Pulse of width T: u(t) − u(t−T). Output = q(t)u(t) − q(t−T)u(t−T), where Q = H/s.
  • Final value (stable): y(∞) = lims→0 sY(s).
