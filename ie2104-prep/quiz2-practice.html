Q1 · Week 4

Simplify a + a′b.

  • A. a
  • B. a + b
  • C. ab
  • D. a′b
Try it yourself first, then reveal the full solution
Answer: B

What it’s asking. Make a + a′b shorter without changing what it does. Here a′ means NOT a, writing two letters together (a′b) means AND, and + means OR. “Simplify” means: find an expression with fewer letters whose output is identical for every input.

Steps needed.

  1. Find out what the expression does in the two cases a = 1 and a = 0.
  2. Recognise the pattern and apply the matching rule.
  3. Confirm with a truth table.
x + x′y = (x + x′)(x + y) = 1 · (x + y) = x + y
xthe variable that appears on its own (here x = a).
x + x′a variable OR its own opposite is always 1, because one of the two is always on.
(x+y)(x+z)the “OR distributes over AND” law, x + yz = (x+y)(x+z). It has no counterpart in ordinary algebra, which is why it feels strange.

What it does: removes a redundant letter. Why you need it: every letter you delete is one fewer gate input. When it works: any time one term is a lone variable and another term contains the complement of that variable.

Case a = 1: the first term is already 1, and 1 OR anything is 1. Case a = 0: a′ = 1, so a′b = b and the whole thing is 0 + b = b. So the output is “1 if a is 1, otherwise copy b”, which is exactly a OR b.

Why the other options are wrong.

  • A. a is the absorption law a + ab = a, which needs the same a in both terms. Here the second term has a′, so at a = 0, b = 1 the original is 1 but option A gives 0.
  • C. ab swaps the OR for an AND; at a = 1, b = 0 the original is 1 but ab is 0.
  • D. a′b keeps only the second term and forgets the lone a; at a = 1, b = 0 the original is 1 but a′b is 0.

Common mistake. Mixing up x + xy = x (same letter, collapses to x) with x + x′y = x + y (opposite letter, the complement just vanishes).

Q2 · Week 4

Which expression equals (a + b′)′ ?

  • A. a′ + b
  • B. a′b′
  • C. a′b
  • D. ab′
Try it yourself first, then reveal the full solution
Answer: C

What it’s asking. Rewrite the NOT of a whole bracket, (a + b′)′, so that the NOT sits on individual letters. The rule that does this is called De Morgan’s law.

Steps needed.

  1. Break the bar over the bracket: change OR to AND and complement each piece.
  2. Cancel any double complement: (b′)′ = b.
  3. Check the answer with a truth table.
(x + y)′ = x′ · y′   and   (x · y)′ = x′ + y′
x, yany pieces, from a single letter up to a whole bracket. Here x = a and y = b′.
rule of thumb“break the bar, change the sign”: the operator flips AND ↔ OR and every piece gets a NOT.
(b′)′NOT of NOT cancels, giving b.

What it does: converts the complement of a combination into a combination of complements. Why you need it: it lets you turn AND-OR forms into NAND/NOR forms and push NOTs down to the inputs. When it works: always, for any number of terms.

Analogy“I will go out if it is NOT (raining OR cold).” That means I go out only when it is not raining AND not cold. The OR turns into an AND once the NOT is pushed inside.

Apply the rule with x = a and y = b′: (a + b′)′ = a′ · (b′)′ = a′b.

  • B. a′b′ changes OR to AND but forgets that b′ is already complemented; (b′)′ is b, not b′.

Q3 · Week 4

Minterm m5 of f(a,b,c) (a = MSB) is:

  • A. a′bc
  • B. ab′c′
  • C. a + b′ + c
  • D. ab′c
Try it yourself first, then reveal the full solution
Answer: D

What it’s asking. A minterm is an AND of all the variables, each plain or complemented, that equals 1 on exactly one row of the truth table and 0 on every other row. m5 is the one for row number 5. “a = MSB” means a is the left-most (most significant) bit of the row number.

Steps needed.

  1. Write 5 as a 3-bit binary number, a first.
  2. Bit 1 → write the variable plain; bit 0 → write it complemented.
  3. AND the three letters together.
mi = product of literals, where literal = x if its bit is 1, and x′ if its bit is 0
ithe row number, written in binary with a as the left-most bit.
bit = 1use the plain variable x, because x = 1 makes that factor 1.
bit = 0use x′, because x = 0 makes x′ = 1.

What it does: builds an AND gate that fires for one chosen input combination only. Why you need it: a function equals the OR of its minterms (sum of minterms, Σm), the starting point for K-maps and decoders. When it works: whenever the term must contain every variable.

5 = 4 + 0 + 1 = 1012, so a = 1, b = 0, c = 1. That gives a · b′ · c = ab′c. Check: with a = 1, b = 0, c = 1 each factor is 1, so the product is 1; change any one input and one factor becomes 0.

Why the other options are wrong.

  • A. a′bc is 011 = m3 (a truth-table check shows it is 1 only on row 3).
  • B. ab′c′ is 100 = m4, an off-by-one slip when converting 5 to binary.
  • C. a + b′ + c is an OR, so it is a maxterm (it is 0 only on row 2, 010), not a minterm.

Common mistake. Using the maxterm rule (0 → plain) on a minterm, or forgetting that a minterm uses AND, not OR.

Q4 · Week 4

Maxterm M3 of f(a,b,c) (a = MSB) is:

  • A. a + b + c
  • B. a′ + b + c
  • C. a + b′ + c
  • D. a + b′ + c′
Try it yourself first, then reveal the full solution
Answer: D

What it’s asking. A maxterm is the mirror image of a minterm: an OR of all the variables that equals 0 on exactly one row and 1 on every other row. M3 is the one that is 0 on row 3.

Steps needed.

  1. Write 3 as 3-bit binary: 011, so a = 0, b = 1, c = 1.
  2. An OR is 0 only if every term is 0, so choose each literal to be 0 on that row.
  3. OR the three literals together.
Mi = sum of literals, where literal = x if its bit is 0, and x′ if its bit is 1
bit = 0use plain x: on that row x = 0, so this term contributes 0.
bit = 1use x′: on that row x = 1, so x′ = 0.
linkMi = (mi)′; each maxterm is the complement of the minterm with the same number.

What it does: builds an OR gate that is 0 for one chosen input combination only. Why you need it: a function equals the AND of its maxterms (product of maxterms, ΠM) taken over the rows where it is 0, the basis of POS form. Note the rule is the opposite of the minterm rule.

Row 011: a = 0 → plain a; b = 1 → b′; c = 1 → c′. So M3 = a + b′ + c′. Check: a = 0, b = 1, c = 1 gives 0 + 0 + 0 = 0; every other row has at least one term equal to 1.

Sanity check. M3 = (m3)′ = (a′bc)′ = a + b′ + c′ by De Morgan. Same result.

Why the other options are wrong.

  • A. a + b + c is M0: it is 0 only at 000.
  • B. a′ + b + c comes from using the minterm rule (1 → plain) inside an OR; it is 0 only at 100, so it is M4.
  • C. a + b′ + c gets the c wrong (plain instead of complemented); it is 0 only at 010, so it is M2.
Q5 · Week 4

The consensus theorem says ab + a′c + bc equals:

  • A. ab + bc
  • B. ab + a′c
  • C. a′c + bc
  • D. ab + a′c + c
Try it yourself first, then reveal the full solution
Answer: B

What it’s asking. Consensus is the extra term you get from two terms that contain a variable and its opposite: from ab and a′c, drop the pair a, a′ and join the leftovers to get bc. The consensus theorem says that in ab + a′c + bc, that third term adds nothing, so it can be deleted.

Steps needed.

  1. Find the two terms with a and a′ (ab and a′c).
  2. Form their consensus (bc) and see it matches the third term.
  3. Delete it; confirm with a truth table.
ab + a′c + bc = ab + a′c
athe “pivot” letter: plain in one term, complemented in the other.
b, cthe leftover letters of those two terms.
bcthe consensus term: the AND of the leftovers. It is redundant.

What it does: deletes a whole product term (one AND gate). When it works: only when a third term equals the AND of the leftovers of a pair of terms containing x and x′. The dual version for POS is (a+b)(a′+c)(b+c) = (a+b)(a′+c).

Why it is redundant: suppose bc = 1, so b = 1 and c = 1. If a = 1, then ab = 1 already. If a = 0, then a′c = 1 already. Either way the OR is already 1, so bc never changes the output.

  • D. ab + a′c + c adds a stray c, which equals ab + c; at 101 the original is 0 but this gives 1.

x ⊕ y (XOR) equals:

Q7 · Week 4

A two-level NAND-NAND circuit directly realises a function in which form?

  • A. Product of sums
  • B. Sum of products
  • C. Exclusive-OR form
  • D. Only functions with a single minterm
Try it yourself first, then reveal the full solution
Answer: B

What it’s asking. A “two-level” circuit has two layers of gates between inputs and output. Here the first layer is NAND gates and the second layer is one NAND gate. Is the result a sum of products (SOP: AND-terms ORed together, like ab + cd) or a product of sums (POS: OR-brackets ANDed together, like (a+b)(c+d))?

Steps needed.

  1. Write the circuit as one expression.
  2. Apply De Morgan to the outer NAND.
  3. Read off the form.
( (ab)′ · (cd)′ )′ = (ab)′′ + (cd)′′ = ab + cd
(ab)′each first-layer NAND makes the complement of one product term.
outer NANDANDs those outputs, then inverts.
De Morgan(P′Q′)′ = P + Q, so the outer NAND acts like an OR of the original products, and the double bars cancel.

What it does: shows that AND-OR logic can be built from NAND gates alone. Why you need it: NAND is a universal gate, cheap and uniform. When to use it: once you have a minimal SOP and your chip only offers NAND gates. NOR-NOR does the same job for POS.

Quick test with real numbers: take a = b = 1. NAND(a,b) = 0, so the output NAND sees a 0 and outputs 1, which agrees with ab + cd = 1. Each first-layer NAND stands for one product term.

Why the other options are wrong.

  • A. Product of sums is what NOR-NOR gives (or OR-AND). NOR looks like “OR”, which is what tempts people.
  • C. Exclusive-OR form is not what this structure gives; XOR is a different gate, not a two-level form.
  • D. Only a single minterm is too narrow: each first-layer NAND is one product term, so you can have as many as you like.

What it’s asking. The dual of an expression is found by swapping AND ↔ OR (and 0 ↔ 1) and leaving every variable and every complement exactly as written. It is not the same as the complement, which flips the output of the whole function.

Minimal SOP of y(a,b,c,d) = Σm(0,1,2,3,7,8,9,10,11,15) (the 2025-26 S2 Q1(b) function):

Answer: A

What it’s asking. A K-map (Karnaugh map) is a truth table redrawn as a grid so that cells next to each other differ in exactly one variable.   3. Read each group: letters that stay constant stay, letters that change vanish.

Common mistake. Stopping at a smaller group (here the four cells 0,1,2,3) when a bigger legal group exists.
