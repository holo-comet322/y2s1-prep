Concept 1 of 8

Induced voltage, torque and commutation

EA = Kφωm   |   Tind = KφIA   |   e = Blv (conductor)   |   F = Bli
EAinternal generated (back) emf of the armature; for a motor it opposes the supply, for a generator it is what the machine produces.
φpole flux per pole, set by the field current IF (and the magnetisation curve).
ωmrotor speed in rad/s (ω = 2πn/60).
Ka constant fixed by the construction (turns, poles).
IAarmature current; torque is flux × armature current.

A loop rotating in a field has an AC emf (2Blv under the poles). Commutation (split-ring commutator + brushes) flips the loop connection every half turn so the terminal voltage is always the same polarity, a mechanical rectifier. The same hardware does the opposite in a motor, keeping the torque in one direction.

AnalogyEA = Kφω is a bicycle dynamo: spin faster or use a stronger magnet and the voltage rises. T = KφIA is the push on a cart: more current or a stronger field gives more force. Fleming’s right-hand rule gives generator action, left-hand rule gives motor action.
Concept 2 of 8

Real machines: armature reaction, and power flow & losses

Problems in real machines (Lecture 7): (1) Armature reaction: the armature mmf distorts the pole flux, shifting the magnetic neutral plane (brushes now short segments that still have voltage, so sparking) and weakening the flux near saturation (generators lose voltage; motors speed up). (2) Inductive kick L di/dt in segments being commutated, also causing sparking. Fixes: brush shifting (impractical, depends on load), interpoles (small series-wound poles that cancel the commutation emf for all loads) and compensating windings (in the pole faces, cancel the armature mmf, so flux weakening and neutral-plane shift are removed).

Losses: PA = IA²RA, PF = IF²RF, brush PBD = VBDIA (2 V), core, mechanical (friction + windage), stray (≈ 1 %, neglected unless stated)
Motor: Pin = VTIL → Pdev = EAIA = Tindωm → Pout = Tloadωm = Pdev − Prot
Generator: Pshaft = Tappωm → Pdev = Pshaft − Prot = EAIA → Pout = VTIL

Prot lumps core and mechanical losses together. η = Pout/Pin. For a separately-excited machine the field supply is an extra input: Pin = VTIL + VFIF (motor) and Pin = Tappωm + VFIF (generator). (This convention reproduces the Tutorial 12 Q2(c) answer of 77.99 %.)

Practice question (lecture 8 set): 240 V shunt motor, IL = 420 A, Pout = 92 504 W, RA = 0.01252 Ω, RF = 32 Ω
  1. IF = 240/32 = 7.5 A; IA = 412.5 A. Copper loss = 412.5²(0.01252) + 7.5²(32) = 2130 + 1800 = 3930 W.
  2. Pin = 240 × 420 = 100 800 W; Prot = 100 800 − 92 504 − 3930 = 4366 W; η = 92 504/100 800 = 91.8 %.
Concept 3 of 8

The shunt (and separately-excited) motor: circuit and equations

IF = VT/RF    IL = IA + IF    VT = EA + IARA    Pdev = EAIA    T = Pdev/ωm
Shuntthe field winding sits directly across the supply, so IF = VT/RF is fixed when VT is fixed. The line current splits: IL = IA + IF (read ‘line current’ vs ‘armature current’ carefully).
Separately excitedthe field has its own supply VF, so IF = VF/RF and IL = IA. With constant VT the two behave identically.
EA = VT − IARAthe back emf: the armature ‘pushes back’ against the supply. RA includes brushes, interpoles and compensating windings if the question says so (Lecture 8 Ex 2).
Speed regulationSR = (nnl − nfl)/nfl × 100 %. A 1750 rpm motor with SR = 4 % has nnl = 1820 rpm.
AnalogyThe motor is a cyclist climbing into a headwind. When the load (hill) gets steeper the motor slows, so the back emf EA drops, which lets the supply push more current IA = (VT − EA)/RA, giving more torque until torque matches load at a slightly lower speed. That self-correcting loop is why a shunt motor’s speed is almost constant.
Lecture 8 Examples 3 & 4 (efficiency) and Example 2 (EA with extra windings)
  1. Ex 3 (needs the curve): 172 kW, 430 V, 1800 rpm separately-excited machine run at 1600 rpm, RA = 0.05. Method: IF = VF/(RF + Radj) → read EA0 at 1800 rpm → scale by 1600/1800 → subtract IARA. Lecture answers: no-load VT = 382 V; at load with compensating windings 364 V; with armature reaction (no compensating windings) 346 V; Radj needed to restore 382 V = 50 Ω.

(b) Internal generated voltage and torque at full load. (c) Armature current and torque at 980 rpm. (d) Input current and output power if EA = 220 V. (e) Input current and EA if the load is disconnected.

Try it yourself first, then reveal the solution
Solution

Formulae: IF = VT/RF; IA = IL − IF; EA = VT − IARA; Pdev = EAIA; Pout = Pdev − Prot; Tdev = Pdev/ωm; η = Pout/(VTIL). Constant flux: EA = Kφωm, T = KφIA.

  1. (a) IL = IA + IF; IF = VT/RF; VT = EA + IARA; EA = Kφωm; Tdev = KφIA (field and armature are in parallel across VT).
  2. (b) IL = 12 000/240 = 50 A; IF = 2.4 A; IA = 47.6 A; EA = 240 − 47.6(0.2) = 230.48 V; Pdev = 10 971 W; T = 10 971/(2π1000/60) = 104.8 N·m.
  3. (c) IF is unchanged (VT fixed) so EA ∝ n: EA = 230.48(0.98) = 225.87 V ⇒ IA = (240−225.87)/0.2 = 70.65 A. Kφ = 230.48/104.72 = 2.201 V·s/rad ⇒ T = 2.201 × 70.65 = 155.5 N·m.
  4. (d) IA = (240−220)/0.2 = 100 A; IL = 102.4 A; Pdev = 220 × 100 = 22 000 W; Pout = 22 000 − 400 = 21 600 W.
  5. (e) No load: Pout = 0 ⇒ Pdev = Prot = 400 W = (240 − 0.2IA)IA ⇒ 0.2IA² − 240IA + 400 = 0 ⇒ IA = 1.669 A (small root). EA = 240 − 0.334 = 239.67 V; IL = 1.669 + 2.4 = 4.07 A.
Concept 4 of 8

New operating point: speed and torque by scaling (the trick behind most Q4 parts)

When the machine moves to a new operating point and the magnetisation is linear (flux ∝ field current), you do not need K at all. Compare the new point with a known one:

EA2/EA1 = (IF2/IF1)(n2/n1)   |   T2/T1 = (IF2IA2)/(IF1IA1)
The question changes…Keep / find
load (IL or IA changes), field unchangedIF same ⇒ EA2 = VT − IA2RA, n2 = n1(EA2/EA1)
Rext in the fieldIF2 = VT/(RF+Rext), then the two formulas above
Rext in the armatureflux unchanged; equal torque ⇒ equal IA; EA2 = VT − IA(RA+Rext)
flux changed to x % of rated (given)EA ∝ φn and T ∝ φIA: IA2 = (T2/T1)IA1/(φ2/φ1)

Quadratic trap: if the question gives Pdev (not IA), solve (VT − IARA)IA = Pdev and take the small root (the large one is an unrealistic stalled-motor current).

AnalogyThink of EA as the speedometer reading (∝ flux × rpm) and the torque as the engine force (∝ flux × current). Weaken the field and each rpm shows less voltage, so the motor must spin faster to produce the same back emf, but each amp makes less torque, so it needs more amps: that is the weak-field speed-up.
Practice question (lecture 9 set): 240 V shunt, 2500 rpm, IL = 37.5 A, RA = 0.37, RF = 160; flux cut to 75 %, extra 1 Ω in the armature, load torque 50 % of rated
  1. IF = 1.5 A, IA1 = 36 A, EA1 = 240 − 36(0.37) = 226.68 V.
  2. Torque ∝ φIA: 0.75 IA2 = 0.5(36) ⇒ IA2 = 24 A.
  3. EA2 = 240 − 24(0.37+1) = 207.12 V; EA2/EA1 = 0.75 × n2/2500 ⇒ n2 = 3046 rpm.
Lecture 8 Example 5: 50 hp, 250 V shunt, RA = 0.06, RF = 50, no-load speed 1200 rpm
  1. No load: EA1 = 250 V at 1200 rpm; IF = 5 A (constant, no armature reaction).
  2. IL = 100 A ⇒ IA = 95 A, EA = 244.3 V, n = 1173 rpm. IL = 200 A ⇒ EA = 238.3 V, 1144 rpm. IL = 300 A ⇒ 232.3 V, 1115 rpm.
  3. Torques T = EAIA/ωm: 189, 388, 587 N·m: speed falls almost linearly with torque, the ‘torque–speed line’ (n = VT/Kφ − RAT/(Kφ)²).

A DC shunt motor has RA = 0.1 Ω and RF = 100 Ω, on a 200-V supply. An external variable resistance Rext is in series with the field; rotational loss 300 W. (i) With Rext = 0, the motor runs at 1200 rpm drawing 200 A: find torque developed, output power and efficiency. (ii) With Rext = 0, find the speed if the line current is 150 A. (iii) Find Rext for 1500 rpm at a line current of 200 A (linear magnetisation).

Try it yourself first, then reveal the solution
Solution

Formulae: IF = VT/RF; IA = IL − IF; EA = VT − IARA; Pdev = EAIA; Pout = Pdev − Prot; Tdev = Pdev/ωm; η = Pout/(VTIL). Linear flux: EA2/EA1 = (IF2/IF1)(n2/n1).

  1. (i) IF = 200/100 = 2 A; IA = 200 − 2 = 198 A; EA = 200 − 198(0.1) = 180.2 V. Pdev = 180.2 × 198 = 35 680 W; ωm = 2π(1200)/60 = 125.66 rad/s ⇒ Tdev = 283.9 N·m.
  2. Pout = 35 680 − 300 = 35 380 W; Pin = 200 × 200 = 40 000 W ⇒ η = 88.4 %.
  3. (ii) Flux is unchanged (IF = 2 A), so EA ∝ n. IA = 148 A ⇒ EA = 200 − 14.8 = 185.2 V ⇒ n = 1200(185.2/180.2) = 1233 rpm (lighter load, faster).
  4. (iii) Let IF = 200/(100+Rext), IA = 200 − IF, EA = 200 − 0.1IA. Scaling: EA = 180.2 × (IF/2) × (1500/1200). Solving gives IF = 1.5996 A ⇒ RF,total = 125.0 Ω ⇒ Rext = 25.0 Ω. (Weaker field ⇒ higher speed.)

Concept 5 of 8

Non-linear analysis: the magnetisation curve and armature reaction

The flux is a non-linear function of mmf (saturation), so accurate answers use the magnetisation curve: EA0 versus IF measured at a reference speed n0. With armature reaction (no compensating windings) the net mmf is NFIF − mmfAR, which is the same as an effective field current IF* = IF − mmfAR/NF. Procedure: (1) find IF* (2) read EA0 from the curve at that IF* (3) correct for speed: EA/EA0 = n/n0.

Lecture 9 Example 1: 50 hp, 250 V shunt, no compensating windings, RA = 0.06, RF = 50, NF = 1200, armature reaction 840 A-turns at IL = 200 A
  1. IA = 195 A, EA = 250 − 195(0.06) = 238.3 V. IF* = 5 − 840/1200 = 4.3 A.
  2. Read EA0 for IF* = 4.3 A from the curve (≈ 233 V at 1200 rpm). Then 238.3/EA0 = n/1200 gives n ≈ 1227 rpm (lecture answer).
  3. Compare 1144 rpm for the same load without armature reaction: the motor with armature reaction runs faster because the flux is weakened. Past-final Q4s all use the linear region, so you will rarely need the graph, but the idea (weak flux ⇒ high speed) explains many conceptual answers.
Concept 6 of 8

Speed control and starting of a shunt motor

From n = VT/(Kφ) − RAT/(Kφ)²:

MethodEffectLimits / region
Field resistance RF ↑IF ↓, φ ↓, speed ↑ (the current rise dominates the flux drop, so torque rises until it matches the load at a higher speed)speeds above base speed; constant-power region (Tmax ∝ 1/n); limited by maximum safe speed
Armature voltage VA (separately excited only)no-load speed shifts, slope unchangedspeeds below base speed; constant-torque region (Tmax = KφratedIA,max)
Series resistance in armaturesteeper curve, speed falls with loadwasteful (I²R loss in the resistor)

The two main methods are complementary: VA below base speed and field weakening above it give speed ranges of up to about 40:1.

Starting: at standstill EA = 0, so IA = VT/RA (250/0.06 = 4167 A, more than 20× rated). A starting resistor in series with the armature limits it and is shorted out in steps (contacts 1A, 2A, 3A) as the back emf builds. Rstart = VT/IA,max − RA.

Lecture 9 Example 2: 25 hp, 240 V shunt, 850 rpm at IL = 91 A; 2.14 Ω inserted in the armature drops the speed to 634 rpm; RA = 0.221, RF = 120
  1. Before: IF = 2 A, IA = 89 A, EA1 = 240 − 89(0.221) = 220.33 V.
  2. Flux unchanged: EA2 = 220.33(634/850) = 164.3 V.
  3. IA2 = (240 − 164.3)/(0.221 + 2.14) = 32.06 A.

Concept 7 of 8

The separately-excited generator

IF = VF/RF    IA = IL    VT = EA − IARA    VR = (Vnl − Vfl)/Vfl × 100 %
EA = Kφωthe no-load terminal voltage (VT = EA when IA = 0).
LoadVT drops with load because of IARA (and extra flux weakening if there is armature reaction).
Controlterminal voltage is set by changing EA: change the speed (rarely possible) or change the field current with Rext in the field circuit (the usual method; EA ∝ IF in the linear region).
  1. From the load, get IA; from VT find EA = VT + IARA.
  2. Scale to the new condition: EA ∝ IF·n.
  3. Efficiency: Pout = VTIL; input = EAIA + Prot + VFIF.
AnalogyA water pump (the prime mover) with a tap (the field current): opening the tap raises the pressure (EA); under heavy flow you lose some pressure in the pipes (IARA).

Concept 8 of 8

The shunt generator: voltage build-up, critical resistance and load line

The field is connected across the armature terminals, so it supplies its own excitation: VT = EA − IARA, IA = IL + IF, IF = VT/RF.

  • Build-up: residual flux gives a small EA, a small IF flows, the flux grows, EA grows, and so on until saturation stops it. The no-load voltage is where the field-resistance line V = RFIF meets the magnetisation curve.
  • Critical resistance: if RF is larger than the slope of the curve’s initial part, the line meets the curve only at the residual voltage and the generator never builds up. Reduce RF.
  • Loaded: EA = VT + IARA. On the graph, find where an IARA gap fits between the magnetisation curve and the field line; the intersection nearer the no-load point is the operating point. The voltage falls more steeply than for a separately excited machine because a lower VT also reduces IF.
Lecture 11 Example 1: shunt generator at 1200 rpm, RA = 0.2, RF = 30 Ω; rheostat set for a no-load voltage of 170 V
  1. The curve gives IF = 3.5 A at 170 V ⇒ RF,total = 170/3.5 = 48.57 Ω ⇒ rheostat = 48.57 − 30 = 18.57 Ω.
  2. With IA = 103.5 A: EA = 48.57IF + 103.5(0.2) = 48.57IF + 20.7. Overlaying this on the curve gives IF = 3 A, EA = 166 V ⇒ VT = 48.57 × 3 = 145.7 V. (Practice question P11 on the same machine: η = 79.45 %.)

✍️ Write This Down

Copy these into your notes:

  • EA = Kφωm; T = KφIA; Pdev = EAIA = Tωm; ω = 2πn/60.
  • Motor: VT = EA + IARA; IL = IA + IF (shunt); Pout = Pdev − Prot; no-load: Prot = EAIA.
  • Generator: VT = EA − IARA; Pout = VTIL; shaft input = EAIA + Prot (+ VFIF if separately excited); VR = (Vnl − Vfl)/Vfl.
  • Linear flux: EA2/EA1 = (IF2/IF1)(n2/n1); T ∝ IFIA. Armature Rext: equal torque ⇒ equal IA. Field Rext: IF falls, speed rises.
  • If Pdev is given, solve (VT − IARA)IA = Pdev and take the small root.
  • Magnetisation curve: IF* = IF − mmfAR/NF; EA/EA0 = n/n0. Armature reaction: flux weakening (motor speeds up; generator voltage drops), neutral-plane shift (sparking). Cures: interpoles, compensating windings.
  • Speed control: VA below base (constant torque), RF above base (constant power). Start with a series armature resistor: Rstart = VT/IA,max − RA.
  • Shunt generator builds up only if RF < Rcritical and residual flux exists.
